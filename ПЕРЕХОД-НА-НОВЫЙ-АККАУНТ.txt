ПЕРЕХОД НА НОВЫЙ (РАБОЧИЙ) АККАУНТ
Google-таблица + key.json + Telegram-бот
========================================

ГЛАВНОЕ
-------
Пересборка программы НЕ нужна: всё, что привязано к аккаунтам,
лежит снаружи exe (файл key.json, settings.json, Apps Script
в таблице). Порядок шагов ниже. Старое можно не удалять, пока
новое не заработало — всё работает параллельно.


ШАГ 1. НОВАЯ GOOGLE-ТАБЛИЦА (НА РАБОЧЕМ АККАУНТЕ)
---------------------------------------------------
1. Войдите в рабочий Google-аккаунт (на почту которого есть доступ).
2. Откройте СТАРУЮ таблицу (она на личном аккаунте, вам выдан доступ).
3. Файл -> Создать копию. Копия создастся НА рабочем аккаунте,
   со всеми данными, листами и кодом Apps Script внутри.
   (Перенос владения «личный -> рабочий» Google часто блокирует,
   поэтому надёжнее именно копия.)
4. Убедитесь, что копия открывается с рабочего аккаунта и данные
   на месте. Старую таблицу пока не трогайте.


ШАГ 2. НОВЫЙ key.json (СЕРВИСНЫЙ АККАУНТ РАБОЧЕГО АККАУНТА)
------------------------------------------------------------
1. Зайдите на console.cloud.google.com ПОД РАБОЧИМ аккаунтом.
2. Создайте проект: вверху выпадающий список проектов ->
   «Новый проект» -> имя, например aganim-bot -> Создать.
3. Подключите два API (меню слева: API и сервисы -> Библиотека):
   - Google Sheets API -> Включить
   - Google Drive API  -> Включить
4. Создайте сервисный аккаунт: API и сервисы -> Учётные данные ->
   «+ Создать учётные данные» -> Сервисный аккаунт ->
   имя, например aganim-bot -> Создать (роль можно не давать) -> Готово.
5. Ключ: откройте созданный сервисный аккаунт (почта вида
   aganim-bot@aganim-bot.iam.gserviceaccount.com) -> вкладка
   «Ключи» -> «Добавить ключ» -> «Создать новый ключ» -> тип JSON ->
   Создать. Скачается файл вида aganim-bot-xxxxxxx.json —
   это и есть key.json.
6. Откройте его Блокнотом, найдите поле "client_email" —
   скопируйте этот адрес.
7. В НОВОЙ таблице (из шага 1): Настроить доступ -> вставить
   client_email -> роль «Редактор» -> Отправить.


ШАГ 3. НОВЫЙ TELEGRAM-БОТ (НА РАБОЧЕМ TELEGRAM)
------------------------------------------------
1. В рабочем Telegram: @BotFather -> /newbot -> имя -> username.
2. Сохраните новый токен (вида 1234567890:AA...).
3. Старый токен отзовите: @BotFather -> /mybots -> старый бот ->
   API Token -> Revoke. ВАЖНО: старый токен лежал в открытом
   GitHub-репозитории, его обязательно надо отозвать.
4. В НОВОЙ таблице: Расширения -> Apps Script. В коде найдите
   строку 9: var BOT_TOKEN = "..." — замените на новый токен.
   (Либо возьмите файл apps_script.gs из этого дистрибутива и
   вставьте его целиком, предварительно вписав новый токен в строку 9.)
   Сохраните (Ctrl+S).
5. Разверните: Начать развертывание -> Новое развертывание ->
   тип «Веб-приложение»:
   - Выполнять от имени: «Я» (рабочий аккаунт)
   - Доступ: «Любой»
   -> Развернуть -> разрешить доступ (Дополнительно -> Перейти).
6. Скопируйте URL веб-приложения
   (https://script.google.com/macros/s/.../exec).
7. Вставьте его в таблицу: лист «Настройки» -> ячейка B2
   (там сейчас URL старого веб-приложения — замените).
8. Установите webhook на новый бот — вставьте в браузер и
   откройте (склейте в одну строку):
   https://api.telegram.org/bot<НОВЫЙ_ТОКЕН>/setWebhook?url=<URL_веб_приложения>
   Должен прийти ответ {"ok":true,...}.
9. Включите бэкапы на новой таблице: в редакторе Apps Script
   выберите функцию setupBackupSystem -> Выполнить (триггеры
   при копировании таблицы не переносятся — это делается один раз).


ШАГ 4. НАСТРОЙКА ЭТОГО ПК
-------------------------
1. Новый key.json положить:
   C:\Program Files\PDF-бот Аганим\key.json        (рядом с pdf_bot.exe)
   или C:\Users\Manager_21\AppData\Roaming\PDF-bot-Aganim\key.json
2. Сменить таблицу: открыть Блокнотом
   C:\Users\Manager_21\AppData\Roaming\PDF-bot-Aganim\settings.json
   и заменить ссылку на НОВУЮ таблицу (взять из адресной строки
   браузера, когда открыта новая таблица).
   Либо просто удалите settings.json — при запуске бот покажет
   окно «Первичная настройка», вставьте туда новый URL -> Сохранить.
3. Перезапустить бота: значок в тре -> Выход -> запустить
   «PDF-бот Аганим» с рабочего стола / из меню Пуск.


ШАГ 5. ПРОВЕРКА (ЧЕК-ЛИСТ)
--------------------------

Если что-то не так: логи C:\Users\Manager_21\AppData\Roaming\
PDF-bot-Aganim\errors.log, типовые проблемы — в конце
ИНСТРУКЦИИ-АДМИНИСТРАТОРУ.txt.


ПРО ПЕРЕСБОРКУ
--------------
Программа пересборки не требует. Сборка теперь бывает двух
вкусов (см. ЧИТАЙ-МЕНЯ.txt): РЕЛИЗ для компаний (без встроенной
таблицы) и ТЕСТ для владельца (таблица владельца + key.json
вшиты, запускается из dist-test). После перехода на рабочий
аккаунт достаточно обновить settings.json и key.json на ПК —
любая сборка подхватит их без пересборки.
