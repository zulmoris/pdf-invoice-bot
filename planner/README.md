# 📅 Планировщик — PWA Календарь-Планировщик

Персональный календарь-планировщик с целями, заметками и статистикой продуктивности.
Работает как Progressive Web App — устанавливается на телефон как обычное приложение.

## ✨ Функции

- **📅 Календарь** — 3 режима: месяц, неделя, день. Свайп навигация на мобилке
- **📝 События** — создание, редактирование, удаление. Повторяющиеся события, категории, приоритеты, завершение с датой выполнения
- **🔔 Напоминания** — push-уведомления в браузере (за 5 мин, 15 мин, 1 час, 1 день)
- **🎯 Цели** — с прогрессом, дедлайном и категориями
- **📓 Заметки** — с привязкой к дате и категории
- **📊 Статистика** — графики активности, события по категориям, статус целей
- **🔍 Поиск** — полнотекстовый с фильтрами по категории и приоритету
- **🌓 Темы** — светлая и тёмная тема
- **💾 Экспорт/Импорт** — бэкап всех данных в JSON
- **📴 Офлайн** — работает без интернета после первого загруза

## 🚀 Деплой на GitHub Pages

### 1. Создать репозиторий

```bash
cd planner
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/zulmoris/planner.git
git push -u origin main
```

### 2. Включить GitHub Pages

1. Открой репозиторий на GitHub
2. **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**, Folder: **/ (root)**
5. Сохранить

### 3. Установить на телефон

1. Открой URL (например `https://zulmoris.github.io/planner/`)
2. В браузере: **«Добавить на главный экран»** (iOS) или **«Установить приложение»** (Android)
3. Готово! 🎉

## 🛠 Технологии

- **Vanilla HTML/CSS/JS** — без фреймворков и сборки
- **IndexedDB** — локальное хранение данных
- **Service Worker** — кэширование и офлайн
- **Chart.js** — графики статистики (CDN)
- **Web Notifications API** — push-уведомления

## ☁️ Синхронизация между устройствами

Синхронизация через Google Sheets + Apps Script. Данные одинаковые на телефоне и компьютере.

### Настройка (один раз)

1. **Создать Google Таблицу** — [sheets.new](https://sheets.new)
2. **Создать 4 листа** с названиями: `events`, `goals`, `notes`, `config`
3. **Вставить заголовки** (строка 1):

   **Лист `events`:**
   ```
   id | title | date | endDate | timeStart | timeEnd | category | priority | repeat | reminder | description | color | completed | completedAt | createdAt | updatedAt
   ```

   **Лист `goals`:**
   ```
   id | title | description | category | deadline | progress | status | createdAt | updatedAt
   ```

   **Лист `notes`:**
   ```
   id | title | content | date | category | createdAt | updatedAt
   ```

   **Лист `config`:** в ячейку **A1** вставь любой случайный токен (например `my-secret-123`)

4. **Вставить Apps Script** — Расширения → Apps Script → вставить код из файла `planner_sync.gs`
5. **Развернуть** — Публикация → Развернуть как веб-приложение:
   - Выполнить от: **Я**
   - Кто имеет доступ: **Любой, даже анонимный**
   - Скопировать **URL веб-приложения**

6. **В Планировщике:** нажми ☁️ Синхронизация → вставь URL → вставь токен → Подключить

### Как это работает

- Каждые 5 минут при активной вкладке — автоматический push
- При переключении на вкладку (с другого устройства) — автоматический pull
- При закрытии вкладки — финальный push
- Конфликты: побеждает более свежая запись (по updatedAt)
