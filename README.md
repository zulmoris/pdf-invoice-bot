# PDF-бот Аганим

Учётная система для салонов: PDF-счёт падает в папку → бот читает
номер/дату/клиента/телефон → данные попадают в Google-таблицу →
Telegram-уведомления команде. Дашборд — просмотр счетов, бонусов
дизайнеров и календаря.

## Состав

| Файл | Назначение |
|---|---|
| `bot_v30.py` | бот (следит за папкой PDF, пишет в таблицу) |
| `dashboard_v30.py` | дашборд (счета / дизайнеры / календарь) |
| `deployment.py` | настройки объекта (какой таблицей работаем) |
| `apps_script.gs` | код для Google Apps Script (уведомления, бэкапы 23:23) |
| `setup.iss` / `update.iss` | установщик и апдейтер (Inno Setup) |
| `release.bat` | сборка релиза (для компаний) |
| `dev_build.bat` | сборка тестовой версии (таблица владельца + key.json) |

## Два вкуса сборки

- **Релиз** (`release.bat <версия>`) — для передачи в компании:
  без встроенной таблицы и ключей; при первом запуске обязательный
  мастер «укажите вашу таблицу».
- **Тест** (`dev_build.bat` → `dist-test\`) — для владельца:
  таблица владельца и `key.json` (из корня проекта) вшиты в exe,
  метка «(тест)». `key.json` в релиз не попадает никогда.

## Инструкции (в корне репозитория)

- `ЧИТАЙ-МЕНЯ.txt` — состав дистрибутива, что где лежит
- `ИНСТРУКЦИЯ-АДМИНИСТРАТОРУ.txt` — развёртывание с нуля на объекте
- `ИНСТРУКЦИЯ-МЕНЕДЖЕРУ.txt` — памятка менеджеру
- `УСТАНОВКА-APPS-SCRIPT.txt` — как «сажать» apps_script.gs в таблицу
- `ПЕРЕХОД-НА-НОВЫЙ-АККАУНТ.txt` — смена Google-аккаунта/таблицы/бота
- `ИСТОРИЯ-ИЗМЕНЕНИЙ.txt` — журнал версий (пополнять сверху)
- `ПАМЯТКА-ДЛЯ-АГЕНТА.txt` — полный контекст проекта для ИИ-ассистента

## Конфиденциальность

`key.json` (ключ сервисного аккаунта Google) и токен бота в
`apps_script.gs` — секреты. `key.json` в git не попадает
(.gitignore); храните его у себя. Токен бота меняется в строке 9
`apps_script.gs` при деплое на своей таблице.

## Быстрый старт сборки

```
python -m venv .venv
.venv\Scripts\pip install pyinstaller watchdog "customtkinter==5.2.2" darkdetect gspread pdfplumber pillow requests openpyxl pystray
release.bat 3.5        # релиз для компаний
dev_build.bat          # тестовая версия владельца
```

Установщик собирается Inno Setup 6 (`setup.iss`, `update.iss`).
