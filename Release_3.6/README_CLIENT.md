# Инструкция по установке и настройке PDF Invoice Bot v3.6

## Для кого эта версия
Эта сборка предназначена для компаний, которые хотят использовать бота самостоятельно.

## Что вам понадобится
1. **Telegram Bot Token**:
   - Создайте нового бота в Telegram через @BotFather.
   - Получите токен (выглядит как 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11).
   
2. **Google Таблица**:
   - Скопируйте шаблон таблицы (ссылка на ваш шаблон).
   - Настройте листы под свои нужды (названия колонок, справочники).
   - Откройте доступ к таблице для сервиса Google Sheets API (если требуется).

## Установка на ПК
1. Скопируйте файл pdf_invoice_bot_v3.6.exe в удобную папку (например, C:\Program Files\PDF_Bot).
2. Запустите файл. При первом запуске появится окно настройки.
3. Введите ваш **Telegram Bot Token**.
4. Введите ссылку на вашу **Google Таблицу** (или ID таблицы).
5. Нажмите "Сохранить" и перезапустите бота.

## Проверка работы
- Отправьте команду /start вашему боту в Telegram.
- Бот должен ответить приветственным сообщением.
- Попробуйте загрузить тестовый документ для генерации счета.

## Обновление
Для обновления до новой версии просто замените файл .exe на новый из релиза. Настройки сохраняются в файле config.json рядом с программой.
