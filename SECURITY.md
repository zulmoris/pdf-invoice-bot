Старый токен Telegram (`7690342745:AAEh5i7YihlNwYzmvDPb_rBWom_IZsYnemE`) был удалён из репозитория.

**Необходимые действия:**

1. **Отозвать старый токен:**
   - Откройте @BotFather в Telegram
   - Отправьте `/revoke`
   - Выберите вашего бота
   - Старый токен будет недействителен

2. **Получить новый токен:**
   - В @BotFather отправьте `/newbot` (или выберите существующего бота)
   - Скопируйте новый токен

3. **Настроить Google Apps Script:**
   - Откройте вашу Google-таблицу
   - Расширения → Apps Script
   - Project Settings (шестерёнка) → Script Properties
   - Добавьте свойство `BOT_TOKEN` со значением нового токена
   - В коде `apps_script.gs` раскомментируйте функцию `getBotToken()`:
     ```javascript
     function getBotToken() {
       return PropertiesService.getScriptProperties().getProperty('BOT_TOKEN');
     }
     ```
   - Закомментируйте или оставьте как есть переменную `BOT_TOKEN` (теперь используется заглушка)
   - Сохраните и разверните заново

4. **Обновить webhook:**
   ```
   https://api.telegram.org/bot<НОВЫЙ_ТОКЕН>/setWebhook?url=<URL_ВЕБ-ПРИЛОЖЕНИЯ>
   ```

## Файлы с секретами

### Локальная разработка (.env)

Для локальной разработки создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Заполните своими значениями:
- `TELEGRAM_BOT_TOKEN` — токен вашего бота
- `GOOGLE_SERVICE_ACCOUNT_KEY` — путь к key.json
- `GOOGLE_SPREADSHEET_URL` — URL вашей таблицы

**Никогда не коммитьте `.env` в Git!** Он уже добавлен в `.gitignore`.

### key.json

Файл `key.json` содержит учётные данные сервисного аккаунта Google:
- **НЕ коммитьте** в репозиторий
- Храните в безопасном месте
- Передавайте только через защищённые каналы
- При компиляции релизной версии **НЕ включайте** в сборку (только для тестовой)
