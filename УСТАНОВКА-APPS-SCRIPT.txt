УСТАНОВКА APPS SCRIPT В GOOGLE-ТАБЛИЦУ (ПОДРОБНО)
==================================================

apps_script.gs — это «сердце» уведомлений: код, который живёт
внутри Google-таблицы и шлёт сообщения в Telegram, делает бэкапы
и ловит удаления строк. Ставится ОДИН раз на каждую таблицу.


КОГДА ЭТО НУЖНО ДЕЛАТЬ
----------------------
- при развёртывании на новом объекте (новая таблица);
- после создания КОПИИ таблицы (код копируется вместе с таблицей,
  но развертывание и триггеры — нет, их надо создать заново);
- при смене Telegram-бота (новый токен);
- при обновлении самого apps_script.gs (новая версия кода).


ШАГ 1. ОТКРЫТЬ РЕДАКТОР
-----------------------
1. Откройте таблицу в браузере (под аккаунтом-владельцем таблицы).
2. Меню: Расширения -> Apps Script.
3. Откроется редактор кода. Если там уже есть код (старая версия
   или Code.gs) — выделите всё (Ctrl+A) и удалите.


ШАГ 2. ВСТАВИТЬ КОД
-------------------
1. Откройте файл apps_script.gs (из этого дистрибутива) Блокнотом.
2. ПЕРЕД вставкой проверьте строку 9 в самом верху файла:
      var BOT_TOKEN = "...";
   Там должен стоять токен ВАШЕГО бота (получается в @BotFather,
   см. ниже «Если бот ещё не создан»). Это единственное место,
   которое надо менять руками.
3. Выделите весь файл (Ctrl+A), скопируйте (Ctrl+C).
4. В редакторе Apps Script вставьте (Ctrl+V).
5. Сохраните: Ctrl+S (или дискета сверху). Имя проекта можно
   оставить какое предложит («Проект без названия» — нормально).


ШАГ 3. РАЗВЕРНУТЬ ВЕБ-ПРИЛОЖЕНИЕ
---------------------------------
1. Кнопка справа вверху: «Начать развертывание» -> «Новое
   развертывание».
2. Шестерёнка рядом с полем «Выберите тип» -> «Веб-приложение».
3. Настройки (ВАЖНО, обе обязательны):
   - Выполнять от имени: «Я» (ваш аккаунт, владелец таблицы)
   - Доступ: «Любой» (иначе Telegram не сможет доставлять ответы
     клиентов — они будут теряться!)
4. Нажмите «Развернуть».
5. Google покажет экран разрешения доступа (это нормально,
   первый запуск):
   - «Приложение не проверено» -> нажмите «Дополнительно»
   - -> «Перейти на страницу (имя проекта) (небезопасно)»
   - -> «Разрешить».
6. Появится URL веб-приложения вида:
   https://script.google.com/macros/s/XXXXXXXX/exec
  СКОПИРУЙТЕ его — он понадобится в шагах 4 и 5.


ШАГ 4. ВБИТЬ URL В ТАБЛИЦУ
--------------------------
В таблице откройте лист «Настройки» и вставьте скопированный URL
в ячейку B2. (Именно оттуда бот и дашборд берут адрес, по которому
отправлять уведомления.)


ШАГ 5. ПОДКЛЮЧИТЬ TELEGRAM (WEBHOOK)
-------------------------------------
Соберите ссылку из двух частей и откройте её в браузере
(в адресной строке, одной строкой):

https://api.telegram.org/bot<ТОКЕН_БОТА>/setWebhook?url=<URL_веб_приложения>

где <ТОКЕН_БОТА> — токен из строки 9 (без кронштейнов),
<URL_веб_приложения> — ссылка из шага 3.

Должен прийти ответ вида {"ok":true,"result":true,...}.
Если пришло "Webhook was set" / ok:true — подключено.


ШАГ 6. ВКЛЮЧИТЬ БЭКАПЫ И ЗАЩИТУ (ОДИН РАЗ)
-------------------------------------------
В редакторе Apps Script вверху есть выпадающий список функций
(рядом кнопка «Выполнить»). Выберите в нём setupBackupSystem
и нажмите «Выполнить» (первый раз снова попросит разрешения —
разрешите, как в шаге 3.5).

Включится: ежедневный бэкап в 23:23 на Google Drive (папка
«Аганим — Бэкапы», хранение 30 дней), часовые снапшоты и тревога
при удалении строк/столбцов.


ЕСЛИ БОТ ЕЩЁ НЕ СОЗДАН
----------------------
1. В Telegram найдите @BotFather (синяя галочка).
2. /newbot -> имя бота (любое, например «Аганим Салон») ->
   username (должен кончаться на _bot, например aganim_salon_bot).
3. BotFather выдаст токен вида 1234567890:AAE4x... —
   это и есть BOT_TOKEN для строки 9.


КАК ОБНОВИТЬ КОД ПОТОМ (БЕЗ ПОТЕРИ НАСТРОЕК)
--------------------------------------------
Если пришла новая версия apps_script.gs:
1. Расширения -> Apps Script -> Ctrl+A -> вставить новый код
   (не забудьте про токен в строке 9!) -> Ctrl+S.
2. «Начать развертывание» -> «Управление развертываниями» ->
   карандаш (изменить) -> Версия: «Новая версия» -> «Развернуть».
   ВАЖНО: именно изменить существующее развертывание, тогда
   URL в B2 и webhook останутся прежними и ничего перенастраивать
   не надо. (Новое развертивание = новый URL = надо менять B2
   и webhook заново.)


КАК ПРОВЕРИТЬ, ЧТО ВСЁ РАБОТАЕТ
--------------------------------
1. Напишите своему боту в Telegram /start — он должен ответить
   числом (ваш chat_id). Молчит -> webhook не установлен (шаг 5)
   или токен неверный.
2. В редакторе Apps Script выберите функцию doGet -> Выполнить —
   в журнале выполнения не должно быть ошибок.
3. Удалите любую строку в Лист1 -> в главный Telegram (Настройки!B1)
   должна прийти тревога, а в Драйве появиться аварийная копия.


ТИПОВЫЕ ОШИБКИ
--------------
- «Развертывание» недоступно / кнопка серая — откройте таблицу
  под аккаунтом-владельцем.
- Уведомления не приходят — проверьте по порядку: B2 заполнен (шаг 4)
  -> webhook ok:true (шаг 5) -> код задеплоен НОВОЙ версией после
  правки токена (см. «Как обновить код потом»).
- Ответы клиентов с кнопок не доходят — в развертывании стоит
  доступ не «Любой» (шаг 3.3).
- Ошибка «Выполнять от имени» — развертывайте под тем же аккаунтом,
  что владеет таблицей.
