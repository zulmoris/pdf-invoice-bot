PDF-БОТ АГАНИМ v3.5 — ДИСТРИБУТИВ (сборка 10.09.2026, вечер)
=============================================================

ДВА ВКУСА СБОРКИ
----------------
1. РЕЛИЗ (эта папка) — для передачи в компании. Внутри exe НЕТ
   встроенной таблицы владельца и НЕТ key.json: при первом запуске
   бот показывает обязательный мастер — компания вставляет ссылку
   на СВОЮ таблицу и кладёт СВОЙ key.json. Ничего вашего с собой
   не уезжает.
2. ТЕСТ (папка dist-test у разработчика, собирается dev_build.bat) —
   для владельца: со встроенной таблицей владельца, exe помечены
   «(тест)», key.json из корня проекта вшивается прямо в exe.
   Меняете код -> dev_build.bat -> запустили dist-test\pdf_bot.exe.

ЧТО В ПАПКЕ
-----------
1. PDF-bot-Aganim-setup-v3.5.exe   — полный установщик (релиз).
2. PDF-bot-Aganim-update-v3.5.exe  — обновление поверх установленной
                                     версии (релиз).
3. apps_script.gs                  — код для Google Apps Script.
4. УСТАНОВКА-APPS-SCRIPT.txt       — как правильно «сажать»
                                     apps_script.gs (подробно).
5. ИНСТРУКЦИЯ-АДМИНИСТРАТОРУ.txt   — развёртывание с нуля (.md тоже).
6. ИНСТРУКЦИЯ-МЕНЕДЖЕРУ.txt        — памятка менеджеру (.md тоже).
7. ПЕРЕХОД-НА-НОВЫЙ-АККАУНТ.txt    — смена Google-аккаунта / таблицы /
                                     Telegram-бота (рабочий аккаунт).
8. ЧИТАЙ-МЕНЯ.txt                  — этот файл.

ВАЖНО ПРО key.json (ЕГО В КОМПЛЕКТЕ НЕТ!)
-----------------------------------------
key.json — ключ сервисного аккаунта Google, в релиз НЕ вшит
(и не должен). Без него программы запускаются, но при обращении
к таблице скажут «key.json не найден».

Куда положить:
  C:\Program Files\PDF-бот Аганим\key.json   (рядом с exe), или
  %APPDATA%\PDF-bot-Aganim\key.json           (в папку данных).

На ЭТОЙ машине старый key.json уцелел: он лежит в
C:\Program Files\PDF-бот Аганим\key.json (от 06.07.2026)
и скопирован в корень проекта (pdf-invoice-bot-master\key.json) —
оттуда он вшьётся ТОЛЬКО в тестовую сборку (dev_build.bat);
в релизную сборку и дистрибутив он не попадает.
Для рабочего аккаунта нужен новый — см. ПЕРЕХОД-НА-НОВЫЙ-АККАУНТ.txt.

СОСТОЯНИЕ ЭТОЙ МАШИНЫ (на вечер 10.09)
--------------------------------------
- В C:\Program Files\PDF-бот Аганим установлена сборка v3.5 от 17:53
  (update.exe от 10.09). Она работает, автозапуск включён.
- Настройки: %APPDATA%\PDF-bot-Aganim\settings.json (таблица
  владельца) и config.json (папка счетов на рабочем столе).
- Обновить до «вечерней» релизной сборки можно в любой момент:
  запустить PDF-bot-Aganim-update-v3.5.exe из этой папки от
  администратора.
- Если бот после обновления был запущен установщиком «от
  администратора» — лучше перезапустить его обычным способом:
  трей -> Выход, затем ярлык с рабочего стола.

ЧТО ПОЧИНЕНО / ДОБАВЛЕНО В ЭТОЙ СБОРКЕ ОТНОСИТЕЛЬНО РЕПОЗИТОРИЯ
----------------------------------------------------------------
- spec-файлы PyInstaller: убраны жёсткие пути со старой системы;
  сборка не падает без key.json.
- Пункт «Открыть дашборд» из меню трея: внутри pdf_bot.exe лежит
  модуль dashboard.py под правильным именем (раньше из-за имени
  файла dashboard_v30.py пункт мог выдавать «No module named
  'dashboard'»).
- Два вкуса сборки: релиз (без таблицы владельца, обязательный
  мастер при первом запуске) и тест (dev_build.bat, таблица
  владельца + key.json вшиты, метка «(тест)»).
- Убран мёртвый BOT_TOKEN из bot_v30.py (не использовался;
  настоящий токен живёт в apps_script.gs, строка 9).
- setup.iss: key.json помечен как необязательный источник.
- release.bat ищет Inno Setup в т.ч. в пользовательской папке.
Собрано: Python 3.14.6, PyInstaller 6.22.2, customtkinter 5.2.2,
Inno Setup 6.7.3. Полные исходники — репозиторий pdf-invoice-bot
(папка pdf-invoice-bot-master).

КАК СОБИРАТЬ
------------
- Релиз (эта папка): release.bat <версия>  из папки репозитория.
- Тест: dev_build.bat (класть свой key.json в корень проекта —
  он вшьётся только в тестовую сборку, в релиз не попадёт).
