ИСТОРИЯ ИЗМЕНЕНИЙ — PDF-бот Аганим
===================================

Как пополнять: новая запись СВЕРХУ, перед предыдущими.
Формат записи: версия — дата — список изменений (что добавлено /
изменено / починено). Если изменения делал агент (ZCode) — он же
и дописывает сюда строку. Обычные правки без релиза можно
записывать как «v3.5.x (правка)».


v3.5 (локальная пересборка) — 10.09.2026
----------------------------------------
Восстановление проекта после потери системы (исходники взяты из
GitHub, машина настроена заново). Версия оставлена 3.5, т.к.
прошлая 3.5 никому не передавалась.

Добавлено:
- Два вкуса сборки:
  * РЕЛИЗ для компаний — без встроенной таблицы владельца и без
    key.json; первый запуск показывает обязательный мастер
    «укажите вашу таблицу», без ввода бот не стартует;
  * ТЕСТ для владельца (dev_build.bat, папка dist-test) — таблица
    владельца и key.json вшиты в exe, метка «(тест)» в окнах/трее.
  Защита: key.json из корня проекта попадает ТОЛЬКО в тестовую
  сборку, в релиз — никогда.
- Дашборд: если таблица не настроена (релиз, нет settings.json) —
  понятное сообщение «настройте через бота» вместо молчаливой
  попытки открыть таблицу владельца.
- Дистрибутив: инструкции в txt (админ, менеджер), подробная
  установка Apps Script, переход на другой аккаунт, памятка для
  агента, бэкап-архив исходников.

Починено:
- Spec-файлы PyInstaller: убраны жёсткие пути со старой системы
  (C:\Users\user\...); сборка не падает, если key.json отсутствует.
- Пункт «Открыть дашборд» из меню трея: в pdf_bot.py-сборке модуль
  дашборда теперь лежит под именем dashboard.py (раньше из-за
  имени файла dashboard_v30.py пункт выдавал ошибку
  «No module named 'dashboard'»).
- release.bat: поиск Inno Setup в т.ч. в пользовательской папке
  (%LOCALAPPDATA%\Programs); защита от отсутствующего
  uninstall_old.bat.
- setup.iss: key.json помечен необязательным источником
  (skipifsourcedoesntexist).

Убрано:
- Мёртвый BOT_TOKEN из bot_v30.py (не использовался; рабочий токен
  живёт в apps_script.gs, строка 9).

Прочее:
- Все правки и инструкции залиты в GitHub (master), добавлен
  README.md; gitignore усилен (dist-test, бэкап-архивы).

Бэкапы 23:23 — уже были и остались: полный бэкап таблицы на Google
Drive (папка «Аганим — Бэкапы», хранение 30 дней), часовой снапшот,
тревога при удалении строк. Включается запуском setupBackupSystem
в Apps Script (один раз на таблицу; после копирования таблицы на
другой аккаунт — включить заново).
