PDF-БОТ АГАНИМ v3.5 — ИНСТРУКЦИЯ ПО РАЗВЁРТЫВАНИЮ
==================================================

Для кого: системный администратор / внедренец.
Цель: запустить систему «с нуля» на новом объекте (новый салон,
новая команда).

Вся система: PDF-счета падают в папку -> программа читает их ->
данные попадают в Google-таблицу -> Telegram-уведомления команде.


0. ЧТО ВХОДИТ В КОМПЛЕКТ
------------------------
1) PDF-bot-Aganim-setup-v3.5.exe  — установщик (бот + дашборд)
2) apps_script.gs                 — код для Google Apps Script
3) ИНСТРУКЦИЯ-МЕНЕДЖЕРУ.txt       — дать менеджеру после настройки
4) PDF-bot-Aganim-update-v3.5.exe — обновление поверх установленной
                                    версии (для уже работающих объектов)

Вам понадобятся от владельца системы:
1) key.json — ключ сервисного аккаунта Google (доступ к API таблиц).
   В дистрибутив он НЕ вшит: положите его после установки рядом
   с pdf_bot.exe или в %APPDATA%\PDF-bot-Aganim\
2) Токен Telegram-бота объекта (создаётся через @BotFather, см. шаг 3)
   или распоряжение использовать общий бот владельца.


1. СОЗДАТЬ GOOGLE-ТАБЛИЦУ ПО ШАБЛОНУ
------------------------------------
1. Сделайте КОПИЮ эталонной таблицы владельца:
   «Файл -> Создать копию» (это сохранит все листы, цвета и структуру).
2. В копии очистите данные (строки счетов, Детализацию, Календарь),
   но НЕ трогайте заголовки и структуру листов.

Обязательные листы и структура (17 колонок A-Q в Лист1):

Лист1 — Счета:
   A №, B дата, C клиент, D телефон, E дизайнер, F к-во поз.,
   G позиции, H поставщик, I № счёта ПОСТ, J дата опл ПОСТ,
   K дата отгр. клиенту, L отправка ТК, M приход ТК КЗН,
   N приход СКЛАД, O дополнительно, P менеджер, Q форма оплаты

Детализация  — бонусы дизайнеров (12 колонок, создаётся ботом при счёте)
Сводка       — агрегация по дизайнерам (заполняется Apps Script)
Календарь    — события: дата, время, текст, тип, выполнено, примечание, создано
Telegram ID  — A имя, B chat_id, C роль (менеджер/дизайнер/руководитель/клиент)
Настройки    — B1 главный рабочий chat_id; B2 URL веб-приложения;
               B10/B11 календарь
Проверка остатков — служебный, можно пустой

3. Откройте доступ для сервисного аккаунта: «Настроить доступ» ->
   вставьте email сервисного аккаунта (виден в key.json, поле
   client_email, вида ...@...iam.gserviceaccount.com) ->
   роль «Редактор».
4. Скопируйте URL таблицы — он понадобится на шаге 6 (см. ниже).


2. УСТАНОВИТЬ ПРОГРАММЫ НА ПК МЕНЕДЖЕРА
----------------------------------------
1. Скопируйте на ПК: setup-v3.5.exe и key.json.
2. Запустите setup-v3.5.exe -> «Далее» -> папка -> «Установить»
   (галки: ярлык на рабочем столе + автозапуск).
3. После установки при первом запуске бот покажет окно
   «Первичная настройка» — вставьте URL таблицы из шага 1 ->
   «Сохранить». (Кнопка «Встроенные настройки» — оставить таблицу
   владельца, не для нового объекта.)
4. Бот попросит выбрать папку для PDF-счетов — укажите рабочую
   папку менеджера.

Настройки сохраняются в %APPDATA%\PDF-bot-Aganim\settings.json
(поменять URL таблицы позже = отредактировать этот файл
и перезапустить бот).


3. TELEGRAM-БОТ ОБЪЕКТА
-----------------------
Если у объекта свой бот (рекомендуется):
1. В Telegram: @BotFather -> /newbot -> имя -> username.
2. Полученный токен вставьте в apps_script.gs (строка BOT_TOKEN).
3. key.json и таблица — свои (шаг 1).

Webhook: после деплоя (шаг 4) установите webhook:
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<URL_веб_приложения>


4. APPS SCRIPT (СЕРДЦЕ УВЕДОМЛЕНИЙ И БЭКАПОВ)
----------------------------------------------
1. Таблица -> Расширения -> Apps Script -> удалите весь старый код ->
   вставьте содержимое apps_script.gs -> Ctrl+S.
2. Начать развертывание -> Новое -> тип «Веб-приложение»:
   - Выполнять от имени: «Я»
   - Доступ: «Любой»
   - Развернуть -> разрешить доступ (Дополнительно -> Перейти).
3. Скопируйте URL веб-приложения
   (https://script.google.com/macros/s/.../exec).
4. Вставьте URL в таблицу: лист «Настройки» -> ячейка B2.


5. ГЛАВНЫЙ TELEGRAM ID (КУДА ПРИХОДЯТ ВСЕ УВЕДОМЛЕНИЯ)
-------------------------------------------------------
1. На телефон главного менеджера: человек пишет боту /start ->
   бот отвечает его числом (chat_id).
2. Это число впишите в «Настройки» -> B1.

Именно сюда будут приходить ВСЕ уведомления: приход товара,
бэкапы, тревоги удаления, заявки клиентов на доставку/самовывоз/
«свяжитесь со мной», а также ответы клиентов и дизайнеров.
Менеджеры счетов дополнительно получают свои события лично (шаг 7).


6. ВКЛЮЧИТЬ БЭКАПЫ И ЗАЩИТУ (ОДИН РАЗ)
---------------------------------------
В редакторе Apps Script выберите функцию setupBackupSystem ->
запустить (кнопка ▶).

Что включится:
- полный бэкап таблицы на Google Drive ежедневно в 23:23
  (папка «Аганим — Бэкапы», хранение 30 дней);
- часовой снапшот данных (восстановление функцией restoreFromSnapshot);
- тревога при удалении строк/столбцов: аварийная копия + алерт
  с email нарушителя в главный Telegram (B1);
- предупреждение при попытке удаления на всех рабочих листах.


7. ЗАВЕСТИ ЛЮДЕЙ
----------------
Лист «Telegram ID»:
   A — имя (как будут вписывать в счета),
   B — chat_id (человек пишет боту /start, пересылает число менеджеру),
   C — роль: менеджер / дизайнер / руководитель / клиент.

- Менеджеры получают уведомления по своим счетам лично.
- Дизайнеры — сообщения о приходе и бонусах.
- Без chat_id человек просто не получает уведомлений (ошибок нет).


8. ПРОВЕРКА (ЧЕК-ЛИСТ ЗАПУСКА)
------------------------------
[ ] Положить тестовый PDF в папку счетов -> открылось окно ввода ->
    строка появилась в «Лист1», бонус — в «Детализации»
[ ] Заполнить у тестового счёта M или N (приход) у всех позиций ->
    в главный Telegram (B1) пришло «все позиции пришли»
[ ] Нажать в этом сообщении «Заберу сам» -> в главный Telegram
    пришло «КЛИЕНТ ЗАБЕРЁТ САМ»
[ ] Открыть «Dashboard Аганим» -> вкладки Счета / Дизайнеры / Календарь
[ ] Apps Script: listBackups -> в журнале список бэкапов (после 23:23)
[ ] Удалить любую строку в Лист1 -> пришла тревога в Telegram


9. ТИПОВЫЕ ПРОБЛЕМЫ
-------------------
Симптом                                   / Причина и решение
--------------------------------------------------------------
Бот молчит, в логе «key.json не найден»   / key.json не рядом с .exe
                                            и не в %APPDATA%\PDF-bot-Aganim
«Нет доступа к Google Sheets»             / Сервисному аккаунту не выдан
                                            доступ к таблице (шаг 1.3)
ТГ-уведомления не приходят                / B2 пуст или код не задеплоен
                                            новой версией; webhook не установлен
Дашборд «Не удалось загрузить данные»     / Неверный URL в settings.json;
                                            проверьте шаг 2.3
Менеджер не получает лично                / У него пустой chat_id
                                            в «Telegram ID»

Логи: %APPDATA%\PDF-bot-Aganim\errors.log
