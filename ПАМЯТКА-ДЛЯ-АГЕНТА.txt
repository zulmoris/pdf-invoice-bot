ЧТО ЭТО ЗА ПРОЕКТ
-----------------
«PDF-бот Аганим» — учётная система для салонов (мебель/дизайн):
1. Менеджер сохраняет PDF-счёт в папку -> бот (bot_v30.py) читает
   номер/дату/клиента/телефон -> окно ввода -> данные попадают
   в Google-таблицу (Лист1 + Детализация бонусов дизайнеров).
2. Дашборд (dashboard_v30.py) — просмотр счетов, дизайнеров,
   бонусов, календаря.
3. Google Apps Script внутри таблицы (apps_script.gs) — шлёт
   Telegram-уведомления (приход товара, заявки клиентов, тревоги
   удаления), делает бэкапы на Drive.
4. deployment.py — настройка «какой таблицей работает объект»
   (settings.json в %APPDATA%\PDF-bot-Aganim).

Репозиторий: https://github.com/zulmoris/pdf-invoice-bot
(ветка master, публичный). Все правки от 10.09.2026 ЗАПУШЕНЫ в
master (коммит «v3.5: пересборка + два вкуса сборки + инструкции»),
GitHub и локальная копия синхронны.
На GitHub НЕ находятся (и не должны): key.json (секрет, gitignore),
сборочные артефакты (dist, dist-test, install_build, build, .venv),
бэкап-архив ИСХОДНИКИ-pdf-invoice-bot-2026-09-10.zip (внутри
key.json) — всё это только локально. Если система слетит:
исходники — с GitHub, key.json — из бэкап-архива или
C:\Program Files\PDF-бот Аганим\key.json (пока жив).

git на машине установлен 10.09.2026 (через winget, пользователю

ДВА ВКУСА СБОРКИ (сделано 10.09)
--------------------------------
- РЕЛИЗ (PDFBOT_FLAVOR=release, по умолчанию) — для компаний:
  без встроенной таблицы владельца и без key.json; первый запуск
  показывает обязательный мастер «вставьте URL вашей таблицы».
  Без URL бот не стартует (show_notification и выход).
- ТЕСТ (PDFBOT_FLAVOR=dev) — для владельца: таблица владельца
  вшита (deployment.py: _OWNER_SHEET_URL), key.json из корня
  проекта вшивается в exe, метка «(тест)» в версии/окнах.
Механика: spec-файлы пишут build\_spec_stage*\_build_flavor.json
({"flavor": "release"|"dev"}) и кладут его в datas; deployment.py
_detect_flavor() читает его в frozen-режиме (нет файла = release;
запуск из исходников = dev). ВАЖНО: spec включает key.json в datas
ТОЛЬКО при flavor=dev — ключ владельца не может утечь в релиз.
